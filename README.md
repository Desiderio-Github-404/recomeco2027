# Recomeço 2027 — Prosperidade em Todas as Áreas

Site estático em HTML, CSS e JavaScript puros. Sem instalações, frameworks, anúncios ou rastreadores.

## Estrutura
- `index.html`: estrutura e conteúdos da aplicação.
- `styles.css`: identidade visual, responsividade e modo claro/escuro automático.
- `app.js`: navegação, cálculos e armazenamento local.
- `data/`: catálogos JSON editáveis, a incluir nas próximas etapas.

## Publicar no GitHub Pages
No repositório, abre **Settings → Pages**. Em **Build and deployment**, selecciona **Deploy from a branch**, escolhe `main` e `/ (root)`, e guarda. O endereço esperado é `https://desiderio-github-404.github.io/recomeco2027/`.

## Actualizar conteúdos
Na Etapa 2, os catálogos serão separados em ficheiros JSON dentro de `data/`. Edita apenas o JSON correspondente, preserva a estrutura e faz commit. Não coloques chaves de API, palavras-passe ou segredos no repositório.

## Privacidade
Metas e registos ficam no armazenamento local do navegador (`localStorage`) deste dispositivo; não são enviados para servidores. Exporta uma cópia antes de limpar os dados do navegador ou trocar de telemóvel.

## Aviso
Conteúdo educativo. Não substitui aconselhamento financeiro, médico, jurídico ou espiritual profissional.
